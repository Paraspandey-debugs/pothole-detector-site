How to Deploy on Render (Free Tier)

Step-by-step 2-minute deployment guide

Option A: 1-Click Render Blueprint (Recommended)

  1. Push this repository to your GitHub account.
  2. Go to Render Dashboard → Blueprints.
  3. Connect this repo. Render will automatically read render.yaml, configure the PyTorch CPU build, and deploy.

Option B: Manual Web Service Setup

  1. Click New Web Service on Render and select your GitHub repo.
  2. Environment: Python 3
  3. Build Command: pip install -r requirements.txt
  4. Start Command: uvicorn app:app --host 0.0.0.0 --port $PORT
  5. Health Check Path: /health
⚡ Why this build is instant: The requirements.txt is pre-configured with the official PyTorch CPU wheel URL (--extra-index-url https://download.pytorch.org/whl/cpu), reducing build download size from 3.5GB to ~150MB, finishing in under 60 seconds on Render!
